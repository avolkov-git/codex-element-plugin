## Различия в доказательствах

- Stage2 добавил отсутствующий у stage1 внешний метод `ИнтерфейсныеКомпонентыОбщегоНазначения.xbsl:7-9`.
- Обе стадии нашли сигнатуру `СоздатьЗамещениеНаСервере:60-61`; stage2 исключил 1 559 лишних символов его тела из строк 62-82.
- Stage2 добавил второй одноимённый метод `ОрганизацииПользовательскийСписокСтрока.xbsl:13-15` и YAML-привязку `:28-30`, не смешивая их с офисным вариантом.
- На неизвестный символ stage1 вернул восемь посторонних кандидатов, stage2: `notFound` без блоков. Ноль в таблице не включает сериализованное сообщение об ошибке.

У stage2 нет провалов по зафиксированному оракулу. Это восемь регрессионных задач,
по которым исправлялась реализация, а не независимая контрольная выборка.

## Протокол и ограничения

- Оракул выбран вручную **до первого запуска**. Полный метод засчитывается только одним непрерывным фрагментом правильного файла; YAML требует точных отступов, ключей и значений, не плоского превью.
- Stage1: **весь замороженный семантический `src`**, не старый pre-AST `HEAD`. Транзитивные импорты из отдельных снимков в памяти; ресурсы NativeAST/YAML из реального корня плагина.
- Одинаковы fixture, запросы, NativeAST `9.1.9-1`, 8 кандидатов, превью 420 символов, дедлайн 8 секунд. **Живого и симулированного LSP нет.** Кандидат зависимости не означает доказанное разрешение компилятора.
- Равные 22k изолируют выходной бюджет, не все внутренние ограничения: stage1 имеет 14k суммарно, 7k на фрагмент и максимум 10 фрагментов; stage2 имеет 32k и другой обход. При 36k повторного retrieval нет.
- Общая рамка docs/rules 60k -> 128k **не исполняется**. Наличие текста в tool-блоке не доказывает его сохранность в полном конечном запросе модели.
- Символы: UTF-16 code units; байты: UTF-8. Дубли: пересечения включённых позиций одного исходника, включая отображение пробелов превью обратно на источник; это не число удаляемых байт prompt.

**Выводов о качестве ответов конечной модели нет:** измеряются доступность
доказательств, объём и локальная задержка извлечения, без вызова модели.
