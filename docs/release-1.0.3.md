# Codex for 1C: Element 1.0.3

Стабильный релиз на основе 1.0.2-rc, принятой после пользовательской проверки в бандле 1C Element 9.2.4-6.

## Изменения

- Чат переведен на React с сохранением прежнего оформления. Виртуализация и пакетные обновления удерживают позицию при прокрутке во время ответа.
- История привязана к подтвержденному пользователю IDE, пространству и имени проекта, а не к экземпляру приложения или пути workspace. Проверка Console работает без внешнего MCP.
- Поиск, изменения, контекст и действия проекта доступны в боковых панелях чата. Уточняющие вопросы принимают ответ прямо в ленте.
- Настройки разделены на тематические разделы. URL приложения для встроенного браузера определяется через IDE; ошибки показываются рядом с соответствующим действием.
- Исправлены проверка Chromium на Windows, комплектность Code Mode для MCP и Cmd/Ctrl+A в поле сообщения, включая русскую раскладку.
- Codex CLI/app-server обновлен до 0.154.0. Экспериментальное управление контекстом включается в «Настройки → Система» при поддержке учетной записью и runtime; по умолчанию выключено.
- Поиск документации вынесен в worker; ограничены очереди потоковых обновлений, запись истории и логов.

## Поставка

- `codex-plugins-1.0.3-win32-x64.zip`
- `codex-plugins-1.0.3-linux-x64.tar.gz`
- `SHA256SUMS.txt` и `README_RELEASE.md`

Выбирайте архив по ОС сервера Element, а не компьютера, на котором открыт браузер. В каждом архиве находятся настоящие бинарники Codex 0.154.0 и управляемый Playwright MCP 0.0.78 с Node.js и Chromium для выбранной платформы. Git LFS pointers в готовые поставки не входят.

## Обновление

1. Сохраните копию каталога плагина и config root. Остановите серверную IDE средствами администрирования Element.
2. Замените содержимое установленного каталога плагина в `/plugins`, сохранив его имя. Не устанавливайте вторую копию с тем же ID.
3. Запустите IDE и проверьте версию 1.0.3 в настройках.

При переходе с 1.0.2-rc дополнительный перенос истории не нужен. Для истории старой ветки 0.1.x используется явный импорт с подтверждением владельца и проекта; исходные данные сохраняются. Подробности находятся в `docs/1.0.0-rc-testing.md` внутри поставки.
