# Codex for 1C: Element 1.0.5

Стабильный выпуск на основе 1.0.5-rc6.

## Изменения

- Просмотр браузера агента в отдельной вкладке рядом с чатом. Передача изображения через CDP и штатный Webview работает в бандле Element без обновления Theia.
- Указатель мыши, подсветка фокуса и ручное управление: клики, прокрутка, ввод русского текста и вставка из буфера. Перед ручным вводом попросите агента подождать.
- Закрытие выбранной страницы кнопкой × и действие «Закрыть остальные» прямо в просмотре браузера.
- Приватные библиотеки Chromium в Linux-поставке для Ubuntu 24.04 x64. Для запуска встроенного браузера не нужно устанавливать системные пакеты вручную.
- Изолированные IDE-сессии 1C Element MCP, привязанные к приложению и проекту текущей IDE. Исправлены подключение IDE группы проектов, передача сессионных заголовков и отображение причин отказа Console.
- Исправлен адрес IPC-сокета просмотра браузера при длинном временном пути Element на Linux.

## Совместимость

Поставка содержит Codex app-server 0.154.0, Playwright MCP 0.0.78, Node.js и Chromium.
Для изолированных IDE-сессий нужен отдельный 1C Element MCP 0.23.0 или новее; для IDE группы проектов нужен MCP 0.23.2 или новее. Актуальный MCP 0.23.3 подходит. Без внешнего MCP работают чаты и встроенный браузер.

Linux-поставка рассчитана на Ubuntu 24.04 x64. Windows-поставка предназначена для Windows x64. ARM64 и macOS в эти два архива не входят.

## Проверки

Выпуск проходит сборку, проверку типов и регрессионные тесты контекста, истории, runtime, IDE-сессий и браузера. CI проверяет запуск app-server и Playwright на целевых Windows/Linux, а Linux-архив дополнительно запускает в чистой Ubuntu 24.04 без сети и установки пакетов.

В ходе rc6 на Docker-стенде Element 9.2.4-6 проверена цепочка «чат → MCP → Playwright → страница входа приложения». Работа после авторизации в приложении и поведение бизнес-логики этой проверкой не подтверждаются. При обновлении целевого сервера проверьте свой проект, MCP и вкладку браузера.

## Поставка

- Windows x64: `codex-plugins-1.0.5-win32-x64.zip`.
- Linux x64: `codex-plugins-1.0.5-linux-x64.tar.gz`.
- Контрольные суммы: `SHA256SUMS.txt`.

Выбирайте архив по ОС сервера Element. Оба архива содержат настоящие бинарники и манифест `codex-plugins/package.json`.

## Обновление

1. Сохраните копию установленного плагина и каталога конфигурации. Остановите серверную IDE средствами администрирования Element.
2. Замените содержимое установленного каталога плагина в `/plugins`, включая `bin` и `browser`. При первой установке перенесите туда каталог `codex-plugins` из архива. Не оставляйте две копии с одним ID.
3. Запустите IDE, обновите страницу браузера и проверьте версию 1.0.5 в настройках.

Переход с rc6 сохраняет формат настроек и истории. Каталог конфигурации удалять не нужно.
