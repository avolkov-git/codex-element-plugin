# Автономный браузер для Linux

Целевая система: Ubuntu 24.04 x64. Плагин содержит Node.js, Playwright MCP, Chromium Headless Shell, необходимые дополнительные библиотеки и шрифты Liberation. На сервере Element не нужны `apt install`, `npx`, отдельный Node.js или доступ в интернет для установки браузера.

Скопируйте каталог плагина в `plugins`, сохранив executable bit. В корне самого плагина должен находиться `package.json`. Не держите рядом две поставки с одинаковым идентификатором расширения. После перезапуска IDE выполните проверку браузера в настройках.

## Что входит в поставку

- `browser/linux-x64/linux-deps/lib`: транзитивные зависимости Chromium, его графических модулей и дополнительные динамически загружаемые модули NSS и Fontconfig.
- `linux-deps/fonts` и `fonts.conf`: локальные шрифты для латиницы и кириллицы; также остаются доступны системные шрифты.
- `linux-deps/licenses`: уведомления об авторских правах и тексты лицензий исходных пакетов Ubuntu.
- `linux-deps/manifest.json`: версии пакетов, ссылки на соответствующие исходники, SHA-256 каждого файла и требования к хосту.
- `codex-chromium` рядом с настоящим бинарником: относительный запускатель, на который указывает `browserExecutablePath` в `runtime.json`.

Запускатель задаёт `LD_LIBRARY_PATH` и параметры Fontconfig только своему дочернему Chromium. Он не меняет `/usr/lib`, глобальные переменные службы, конфигурацию Element или окружение Codex. Каталог плагина может быть доступен только для чтения; профили, кэш и временные файлы браузера записываются вне него.

Базовые glibc и загрузчик ELF не подменяются. Совместимость с Alpine/musl, ARM64 и другими дистрибутивами этой проверкой не подтверждается. Нужны разрешённый запуск процессов, права выполнения файлов и доступные для записи временные каталоги пользователя службы. Политики ядра, sandbox, noexec и сетевые ограничения сервера остаются в силе.

## Сборка

`scripts/prepare-browser-runtime.js` на Ubuntu 24.04 устанавливает зависимости Chromium на сборочном runner и вызывает `scripts/linux-browser-dependencies.js`. Последний собирает приватную копию библиотек, формирует относительный запускатель и манифест. Скрипт отказывается собирать этот комплект на другой ОС или архитектуре. Windows-ветка сборки не изменяется.

Для обновления уже подготовленного Linux runtime на сборочной Ubuntu:

```sh
node /path/to/runtime/node/node /path/to/runtime/node_modules/playwright/cli.js install-deps chromium
node scripts/linux-browser-dependencies.js /path/to/runtime
```

Установка пакетов разрешена только на сборочной машине. На сервере пользователя этот шаг не выполняется.

Проверка поставки сверяет хеши приватных библиотек, настоящего Chromium и запускателя, запрещает symlink вместо файла и смешение архитектур. Linux release packaging не принимает прежний runtime без `linuxDependenciesPath`. При обновлении Playwright или пакетов Ubuntu нужно пересобрать комплект и повторить чистую проверку: пакеты внутри плагина не обновляются через `apt` на сервере.

Сторонние компоненты сохраняют собственные лицензии, а не MIT-лицензию плагина. При публичном распространении необходимо сохранить уведомления и обеспечить предоставление соответствующих исходников согласно условиям этих компонентов; ссылки и точные версии записаны в манифесте.

## Проверка без установленных зависимостей

CI распаковывает итоговый TAR.GZ и запускает `scripts/linux-browser-clean-smoke.cjs` в отдельной `ubuntu:24.04`:

- UID 1000, корневая файловая система только для чтения;
- внешняя сеть отключена, доступен только loopback для тестового HTTP-приложения;
- не устанавливаются пакеты, база `dpkg` не должна измениться;
- отрицательная проверка подтверждает отсутствие системной `libgbm.so.1`;
- затем штатные сервисы плагина запускают Chromium через приватные библиотеки;
- проверяются MCP-навигация и клик, непустые JPEG-кадры CDP, указатель агента, ручной ввод кириллицы, закрытие остальных/последней вкладки и повторное открытие.

Проверяются собранные файлы `dist` и runtime из поставки, а не подменённый системный Chrome. Это проверка браузерного комплекта, не сквозной запуск сервера Element с реальной учётной записью.
