# Закрытие пяти ограничений проектного контекста

Дата: 14 октября 2026. База: `3ad75e409940e63350712049d0a0f5d09f024b84`, ветка `master`, версия `1.0.4`.

Закрыты пять ограничений из [предыдущего отчёта](2026-10-14-context-fixes.md). Исходный аудит теперь проходит полностью: **54/54**, дополнительные подтверждения **5/5**. В работе участвовали три параллельных исполнителя с отдельными областями ответственности: документация, извлечение ссылок AST, независимые сценарии отбора. Интеграцию и общие прогоны проверил основной исполнитель.

## Изменения

| Ограничение | Реализация | Проверка |
| --- | --- | --- |
| R03: только два начальных компонента | Все явно названные компоненты рассматриваются в пределах файлового бюджета; YAML и парные XBSL загружаются вместе. Пропущенные компоненты перечисляются. Совпадение имени обработчика не добавляет чужую форму, если явно названный компонент уже содержит этот метод. | Исходный R03; три компонента с двумя обработчиками каждый; 14 компонентов сверх бюджета; одноимённые обработчики разных форм. |
| R04: посторонние обработчики | Именованный контрол или ссылка на метод задают точный YAML-фокус. Границы содержащего mapping берутся из штатного YAML-парсинга, в том числе для кнопок и надписей без `Имя`. Широкие fallback-фрагменты и поисковые превью больше не расширяют этот фокус. | Исходный R04; именованные и безымянные контролы, дополнительный явно названный метод, запрос всей формы. |
| R07/C3: поздние зависимости | Явно запрошенные вызовы имеют приоритет. Повторы делят один слот группы зависимостей, но сохраняют точные позиции. Сначала каждой группе выделяется одно вхождение, затем распределяется оставшийся бюджет. Пропуски отмечаются. | Исходные R07/C3; локальные и общие модули после 18 повторов; 100 повторов перед другой зависимостью; циклы и переполнение. |
| AST/LSP S4: `MethodRef` | Общий extractor распознаёт вызовы, ссылки на методы и типы. `&ИмяМетода` передаётся LSP по точной UTF-16 позиции. Без LSP простая незатенённая ссылка остаётся структурным кандидатом; квалифицированные ссылки не связываются с одноимённым локальным методом. | Исходный S4; настоящий AST, CRLF/non-BMP, generic-параметры, конструкторы, `this`/`global`, затенение параметром и вложенной лямбдой. |
| Docs S02: точный заголовок за fuzzy top-12 | Отдельный exact-title режим сканирует загруженный корпус до применения лимита выдачи. Версия документации учитывается до top-k; сохраняются ID, provenance, границы идентификаторов, дедупликация и worker-контракт. | Исходный S02; 80 fuzzy-заголовков, более 12 точных заголовков разных версий, пересекающиеся корни, смена корпуса и асинхронный worker. |

Основные файлы: `src/projectSemanticService.ts`, `src/projectStructure.ts`, `src/projectToolsService.ts`, `src/projectAstReferences.ts`, `src/docsSearchEngine.ts`, `src/docsToolsService.ts`, `src/docsSymbolMatching.ts`.

Регрессии закреплены в `tests/project-semantic-coverage.test.cjs`, `tests/project-semantic-reference-limits.test.cjs`, `tests/project-ast-references.test.cjs`, `tests/docs-exact-lookup.test.cjs`. ## Тестовый проект

`privet-dom-app`, commit `5f3e72ed3afed7d04b9af8b700fe5094c847ee32`: 1014 файлов, 4625 поисковых фрагментов. Замер использует прежний frozen oracle, те же восемь задач и настоящий AST, без работающего LSP. Oracle и проект не изменялись; исходники и ресурсы стабильны на протяжении финального прогона.

Объём суммируется по восьми задачам и измеряется в символах, не токенах. При 36k он уменьшился примерно на 13,3% без потери проверяемого покрытия. Целью остаётся качество контекста: первичны полные нужные методы и связи, а не размер ответа. Эталонный этап 1 по-прежнему проходит 4/8 задач.

Первый промежуточный замер выявил потерю окружающих свойств у безымянных YAML-контролов и лишний выбор формы с одноимённым методом. Они исправлены и закреплены отдельными новыми тестами; oracle не ослаблялся. Дополнительное ревью выявило затенение внешней ссылки параметром вложенной лямбды и вытеснение зависимости большим числом повторов; оба случая также исправлены.
