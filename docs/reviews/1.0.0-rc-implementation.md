# 1.0.0-rc

Цель: устранить проблемы чата при прокрутке во время ответа и добавить проверенные возможности desktop в рамках API поставки 1C Element 9.2.4-6. История принадлежит подтвержденному пользователю IDE и именованному проекту, а не экземпляру приложения или пути workspace.

Изолированная ветка: `codex/1.0.0-rc`. Стабильная `master` и ее каталоги поставки не изменяются сборкой RC.

## Границы

- Данные Console `/api/v2/me` и `/api/v2/projects/{id}` запрашиваются с учетными данными текущей IDE. Глобальный активный MCP-контекст не является удостоверением личности.
- Ключ истории: сервер Console + список пользователей + пользователь; пространство + имя проекта. Application ID и путь workspace не входят в ключ.
- Неизвестная или поврежденная история не считается пустой и не перезаписывается. Конкурирующие изменения одного чата сохраняются как конфликт, а не теряются.
- Старые произвольные профили не выбираются автоматически. Импорт требует подтверждения владельца и проекта; исходник остается на месте.
- В новом workspace нельзя молча продолжать backend thread со старым cwd.
- Element worktree, произвольные native terminal/Git операции и системные обходы ограничений не обещаются. Действия IDE доступны только при проверенной поддержке API.
- Локальные фикстуры не заменяют испытание RC внутри реальной IDE на Windows/Linux под системным пользователем. Эти проверки остаются приемочными, даже при зеленых тестах сборки.
