# Codex for 1C: Element 1.0.4

В этом релизе расширили подбор проектного контекста и проверку последствий изменений кода.

## Изменения

- Связали YAML, XBSL и документацию через структурный индекс, ответы работающего Language Server и штатный AST из бандла Element. При недоступности источника плагин отмечает ограничение проверки.
- Добавили подбор контекста под задачу, кеширование с обновлением при изменениях и адресные правила из `.local-codex/rules/`. Общепроектные правила из `.local-codex/rules.md` сохраняются.
- Добавили проверку связей и диагностик после правок. В следующий запрос передаётся актуальный отчёт с указанием неподтверждённых связей и пропусков.
- Исправили 13 проблем ревью: гонки отмены и очереди запросов, устаревшие снимки и отчёты, блокировку индекса после таймаута, пропуск правил из несохранённых файлов, потерю ошибок IDE и неполную проверку AST/LSP.
- Учли парные модули объекта, набора записей и записи. Вложенные методы участвуют в поиске затронутого кода, но не становятся обработчиками YAML уровня модуля.
- Проверяем диапазоны LSP целиком. Совпадение имени файла или метода само по себе не подтверждает связь.

## Проверки

На рабочей станции прошли 941/941 тест без пропусков, `npm run build` и `npm run check`. Независимый повтор ревью прошёл 12/12 групп, включая 240 прежних контрольных тестов и 6/6 сценариев на `privet-dom-app`.

Штатный AST запускали из бандла Element. События IDE, RPC и ответы LSP в регрессионных тестах моделировали. Живую Windows IDE и прикладное приложение в этом прогоне не запускали; эти проверки не доказывают корректность итогового кода модели или бизнес-логики приложения.

Ограничения анализа и результаты исправлений: [проверка изменений](project-change-review.md).

## Поставка

- Windows x64: `codex-plugins-1.0.4-win32-x64.zip`.
- Linux x64: `codex-plugins-1.0.4-linux-x64.tar.gz`.
- Контрольные суммы: `SHA256SUMS.txt`.

Выбирайте архив по ОС сервера Element. Каждый архив содержит Codex app-server 0.154.0 и Playwright MCP 0.0.78 с Node.js и Chromium для своей платформы. ARM64 в эти архивы не входит. Готовая поставка должна проходить строгую проверку без Git LFS pointers.

## Обновление

1. Сохраните копии установленного плагина и config root. Остановите серверную IDE средствами администрирования Element.
2. Распакуйте архив и замените содержимое установленного каталога плагина в `/plugins`, сохранив его имя. При первой установке перенесите туда каталог `codex-plugins`. Не оставляйте две копии плагина с одним ID.
3. Запустите IDE, обновите страницу браузера и проверьте версию 1.0.4 в настройках.

Переход с 1.0.3 не меняет схему привязки истории к пользователю IDE, пространству и имени проекта. Каталог конфигурации не нужно удалять.
